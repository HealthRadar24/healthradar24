Support

HealthRadar24 is an attributed open-source fork of WorldMonitor, operated independently by Kernelius. The upstream project does not provide support for this deployment.

Billing is not publicly enabled. No HealthRadar24 subscription should currently charge you. If you believe you were charged, open a private account-support request through the repository security channel and do not include card details.

Where to get help

ConcernChannel
Bug or feature requestHealthRadar24 GitHub issues
Security vulnerabilityPrivate vulnerability report
Service healthLive compact health report
Account, privacy or future billing supportUse the contact form on the HealthRadar24 Pro page. Do not post personal information in a public issue.

Useful diagnostic information

Include the affected URL, approximate time and timezone, browser or client version, and any request ID. Never send passwords, complete API keys, session tokens, payment-card details or provider credentials.
